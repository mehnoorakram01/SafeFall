# SafeFall

SafeFall is an Android application designed to detect potential falls using smartphone sensors and automatically notify guardians in emergency situations. The application can send SMS alerts with the user's location and maintain a history of detected fall events.

## Features

* Fall detection using device sensors
* Automatic emergency SMS alerts
* Guardian contact management
* Location sharing during emergencies
* Fall history tracking
* User-friendly Android interface

## Technologies Used

* Java
* Android Studio
* SQLite Database
* Android Sensors API
* Android Location Services
* SMS Manager

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/SafeFall.git
   ```

2. Open the project in Android Studio.

3. Allow Gradle to sync.

4. Connect an Android device or start an emulator.

5. Run the application.

## Purpose

SafeFall aims to improve user safety by providing rapid emergency notifications when a fall is detected. The application is particularly useful for elderly individuals, patients, and anyone requiring emergency monitoring.
